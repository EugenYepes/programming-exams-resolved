# Parcial resuelto en C – Sistema de Gestión Hospitalaria (structs anidados y malloc)

🎥 Video explicación: Próximamente

## Qué vas a aprender
- **Structs anidados:** Modelar entidades relacionadas (Hospital → Clínica → Paciente).
- **Memoria dinámica (`malloc`/`free`):** Reservar memoria en tiempo de ejecución para arrays de tamaño variable.
- **Punteros a structs:** Modificar datos desde funciones sin copiarlos.
- **Menú interactivo:** Uso de `do-while` + `switch` para ciclos de entrada del usuario.
- **Búsqueda lineal:** Encontrar elementos por código en un array de structs.
- **Validaciones de negocio:** Control de duplicados, límites y disponibilidad.
